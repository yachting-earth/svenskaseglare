# Sailserver

Nedan hittar du data som vår Sailserver registrerar ombord. När vi ankrat och inte är ombord håller den ett öga på Freya, och meddelar oss via både SMS och larm, om ankaret inte sitter som det ska, om vinden plötsligt ökar eller ändrar riktning. När vi seglar så registrerar den såklart rutten, vår hastighet, hur mycket vi lutar, vindhastighet, riktning och mycket annat.

Klicka på "mappen" (andra ikonen från vänster) längst ner på sidan för att se våra tidigare rutter.
